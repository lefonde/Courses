הכלים הנחוצים

לפתרון השאלה נשתמש בכלים הבאים מתוך חומר הקורס:

התפלגות סטציונרית:

וקטור הסתברויות \(\pi\) המקיים שוויון תחת מעברי השרשרת (\(\pi P = \pi\)). ההסתברות להימצא במצב מסוים בצעד הבא שווה לסכום ההסתברויות להימצא במצבים הקודמים כפול הסתברות המעבר מהם.

המשפט המרכזי של שרשראות מרקוב:

עבור שרשרת סופית, אי־פריקה ובלתי־מחזורית (אפריודית), מתקיימים התנאים הבאים:

  • קיימת התפלגות סטציונרית יחידה \(\pi\).
  • לכל מצב \(v\), ההתפלגות הסטציונרית \(\pi_v\) הופכית לתוחלת זמן החזרה למצב, קרי \(\pi_v = \frac{1}{h_{v,v}}\).

תוחלת צעד ראשון:

תוחלת הזמן הנדרש לעבור ממצב למצב מחושבת כ־1 (הצעד הנוכחי) ועוד תוחלת זמן ההגעה מהמצבים הבאים, משוקללת בהסתברויות המעבר אליהם.

התרגיל הבסיסי (תרגיל מעובד לחזרה)

שאלה:

נתונה שרשרת מרקוב המבוססת על הגרף מהבחינה, אך עבור \(n=2\). קבוצת הקדקודים היא \(\{0, 1, 2\}\). מכל קדקוד \(i \in \{0, 1\}\) יוצאת צלע ל־\(i+1\) וצלע ל־\(0\) בהסתברות אחידה. מקדקוד \(2\) יוצאת צלע לעצמו וצלע ל־\(0\) בהסתברות אחידה.

  1. כתבו את משוואות ההתפלגות הסטציונרית וחשבו אותה.
  2. חשבו את תוחלת זמן ההגעה מ־\(0\) ל־\(2\), כלומר את \(h_{0,2}\).
רמז

סמנו ב־\(\pi_0, \pi_1, \pi_2\) את ההתפלגויות הסטציונריות. שימו לב שהדרך היחידה להגיע ל־\(1\) היא דרך \(0\), ול־\(2\) אפשר להגיע מ־\(1\) או מ־\(2\). לחישוב \(h_{0,2}\) תוכלו להשתמש בקשר לזמן החזרה \(h_{2,2}\).

פתרון

התפלגות סטציונרית:

ננסח את משוואות המעבר:

  • ל־\(1\) מגיעים רק מ־\(0\): \(\pi_1 = \frac{1}{2}\pi_0\)
  • ל־\(2\) מגיעים מ־\(1\) ומ־\(2\): \(\pi_2 = \frac{1}{2}\pi_1 + \frac{1}{2}\pi_2\). מכאן נובע \(\frac{1}{2}\pi_2 = \frac{1}{2}\pi_1\), ולכן \(\pi_2 = \pi_1 = \frac{1}{2}\pi_0\).

סכום ההסתברויות הוא \(1\):

\[\pi_0 + \pi_1 + \pi_2 = 1\] \[\pi_0 + \frac{1}{2}\pi_0 + \frac{1}{2}\pi_0 = 1 \implies 2\pi_0 = 1 \implies \pi_0 = \frac{1}{2}\]

ההתפלגות הסטציונרית היא: \(\pi = (\frac{1}{2}, \frac{1}{4}, \frac{1}{4})\).

תוחלת זמן ההגעה \(h_{0,2}\):

לפי המשפט המרכזי של שרשראות מרקוב, זמן החזרה ל־\(2\) הוא הופכי להתפלגות הסטציונרית שלו:

\[h_{2,2} = \frac{1}{\pi_2} = \frac{1}{1/4} = 4\]

נבטא את זמן החזרה \(h_{2,2}\) על ידי הצעד הראשון מתוך \(2\): בהסתברות \(\frac{1}{2}\) נחזור מיד ל־\(2\) (צעד אחד), ובהסתברות \(\frac{1}{2}\) נעבור ל־\(0\) (צעד אחד) ומשם נצטרך \(h_{0,2}\) צעדים נוספים.

\[h_{2,2} = \frac{1}{2}(1) + \frac{1}{2}(1 + h_{0,2}) = 1 + \frac{1}{2}h_{0,2}\]

נציב את \(h_{2,2}=4\) שחישבנו:

\[4 = 1 + \frac{1}{2}h_{0,2} \implies 3 = \frac{1}{2}h_{0,2} \implies h_{0,2} = 6\]

שאלת הבחינה

נוסח השאלה:

נתונה שרשרת מרקוב המתקבלת מהילוך מקרי על הגרף המכוון הבא. קבוצת הקדקודים הינה \(0, \dots, n\), כשמכל קדקוד יוצאות שתי צלעות בדיוק, וכל אחת מהצלעות נבחרת בהתפלגות אחידה. מקדקוד שמספרו \(i \le n-1\) יוצאת צלע אחת לקדקוד מספר \(i+1\) וצלע שנייה לקדקוד מספר \(0\). מהקדקוד האחרון, שמספרו \(n\), יוצאת צלע אחת לעצמו וצלע שניה לקדקוד מספר \(0\).

  1. מצאו את ההתפלגות הסטציונרית של השרשרת.
  2. הוכיחו שתוחלת הזמן הנדרש להגעה מקדקוד \(0\) לקדקוד \(n\), \(h_{0,n}\), הינה מעריכית \(\Theta(2^n)\).
רמז לסעיף א

בטאו כל \(\pi_i\) (עבור \(1 \le i \le n-1\)) כתלות ב־\(\pi_{i-1}\), ומצאו חוקיות עד \(\pi_0\). עבור \(\pi_n\), שימו לב למעבר העצמי המקיים \(\pi_n = \frac{1}{2}\pi_{n-1} + \frac{1}{2}\pi_n\). לבסוף, השוו את סכום כל האיברים ל־\(1\).

רמז לסעיף ב

אל תנסו לבנות מערכת של \(n\) משוואות לחישוב \(h_{0,n}\). היעזרו בתוצאת סעיף א ובמשפט המרכזי כדי למצוא את זמן החזרה \(h_{n,n}\). לאחר מכן, בטאו את התוחלת \(h_{n,n}\) לפי תוצאת הצעד הראשון מתוך \(n\), וחלצו את \(h_{0,n}\).

פתרון מלא

סעיף א — התפלגות סטציונרית:

נסמן את ההתפלגות הסטציונרית ב־\(\pi = (\pi_0, \dots, \pi_n)\).

עבור כל קדקוד \(i \in \{1, \dots, n-1\}\), הדרך היחידה להיכנס אליו היא באמצעות צלע מקדקוד \(i-1\). מכיוון שמכל קדקוד בוחרים צלע בהסתברות \(\frac{1}{2}\), משוואת ההתפלגות הסטציונרית היא:

\[\pi_i = \frac{1}{2}\pi_{i-1}\]

על ידי הפעלת הקשר הזה ברקורסיה עד הגעה ל־\(0\), מתקבל:

\[\pi_i = \left(\frac{1}{2}\right)^i \pi_0\]

עבור הקדקוד \(n\), נכנסות אליו צלעות מקדקוד \(n-1\) וכן צלע עצמית מ־\(n\). לכן משוואתו היא:

\[\pi_n = \frac{1}{2}\pi_{n-1} + \frac{1}{2}\pi_n\]

החסרת \(\frac{1}{2}\pi_n\) משני האגפים נותנת \(\frac{1}{2}\pi_n = \frac{1}{2}\pi_{n-1}\), כלומר:

\[\pi_n = \pi_{n-1} = \left(\frac{1}{2}\right)^{n-1} \pi_0\]

נדרוש שסכום ההסתברויות יהיה \(1\):

\[1 = \sum_{i=0}^n \pi_i = \pi_0 + \sum_{i=1}^{n-1} \left( \left(\frac{1}{2}\right)^i \pi_0 \right) + \pi_n\]

נוציא את \(\pi_0\) כגורם משותף, ונשתמש בסכום סדרה הנדסית לאיברים הפנימיים \(\sum_{i=1}^{n-1} (\frac{1}{2})^i = 1 - \frac{1}{2^{n-1}}\):

\[1 = \pi_0 \left[ 1 + \left(1 - \frac{1}{2^{n-1}}\right) + \frac{1}{2^{n-1}} \right] = \pi_0 [ 2 ] \implies \pi_0 = \frac{1}{2}\]

נציב בחזרה לקבלת ההתפלגות המלאה:

  • \(\pi_0 = \frac{1}{2}\)
  • \(\pi_i = \left(\frac{1}{2}\right)^{i+1}\) (עבור \(1 \le i \le n-1\))
  • \(\pi_n = \left(\frac{1}{2}\right)^n\)

סעיף ב — תוחלת זמן ההגעה \(h_{0,n}\):

תחילה נוודא שהמשפט המרכזי של שרשראות מרקוב מתקיים. השרשרת סופית. היא אי־פריקה כיוון שמכל קדקוד \(i\) ניתן להגיע ל־\(0\), ומ־\(0\) ניתן להגיע לכל קדקוד דרך המסלול \(0 \to 1 \to \dots \to i\). היא בלתי־מחזורית (אפריודית) כיוון שיש לקדקוד \(n\) (וגם ל־\(0\)) קשת לעצמו המאפשרת מעבר באורך \(1\).

לכן, לפי המשפט, מתקיים:

\[h_{n,n} = \frac{1}{\pi_n} = \frac{1}{(1/2)^n} = 2^n\]

כעת, ננתח את זמן החזרה \(h_{n,n}\) על ידי פירוק הצעד הראשון מתוך \(n\):

  • בהסתברות \(\frac{1}{2}\) ההילוך לוקח את הצלע העצמית ל־\(n\), ולכן חזרנו בצעד אחד.
  • בהסתברות \(\frac{1}{2}\) ההילוך לוקח את הצלע ל־\(0\) (שזה צעד אחד), ומשם נדרשים בממוצע עוד \(h_{0,n}\) צעדים כדי להגיע שוב ל־\(n\).

נסכם זאת למשוואה:

\[h_{n,n} = \frac{1}{2}(1) + \frac{1}{2}(1 + h_{0,n}) = 1 + \frac{1}{2}h_{0,n}\]

נציב את ערכו של \(h_{n,n}\) שמצאנו:

\[2^n = 1 + \frac{1}{2}h_{0,n}\] \[\frac{1}{2}h_{0,n} = 2^n - 1\] \[h_{0,n} = 2^{n+1} - 2\]

מכיוון שקיימים קבועים חיוביים החוסמים את הביטוי \(2^{n+1} - 2\) משני צדדיו בעזרת כפולות של \(2^n\) (עבור \(n\) גדול מספיק), הסקנו כי \(h_{0,n} = \Theta(2^n)\).

בדיקת הבנה

  1. מדוע \(\pi_n\) אינו שווה ל־\(\frac{1}{2}\pi_{n-1}\) כמו שאר הקדקודים?
  2. האם השרשרת הייתה מקיימת את התנאי לשימוש במשפט החזרה אילו הקשת מ־\(n\) לעצמו לא הייתה קיימת?
  3. בפיתוח המשוואה \(h_{n,n} = 1 + \frac{1}{2}h_{0,n}\), היכן מיוצג הצעד הראשון שיוצא מ־\(n\)?
תשובות
  1. כי לקדקוד \(n\) נכנסת קשת נוספת — קשת הלולאה מעצמו. שתי הקשתות תורמות יחד למשוואת המצב הסטציונרי: \(\pi_n = \frac{1}{2}\pi_{n-1} + \frac{1}{2}\pi_n\).
  2. כן. כדי ששרשרת תהיה בלתי־מחזורית, די בכך שיהיה לפחות מעגל אחד באורך שאינו כפולה של אורך מחזור משותף. הקשת מ־\(0\) ל־\(0\) לבדה מבטיחה שהמחזור המשותף המקסימלי הוא 1.
  3. הצעד הראשון מיוצג בספרה \(1\) שבתוך הסוגריים עבור כל אחת מההסתברויות: חצי כפול \((1)\), וחצי כפול \((1 + h_{0,n})\). לאחר פתיחת הסוגריים, סכום החצאים של הספרה \(1\) מהווה את ה־\(1\) החופשי במשוואה.

ערכים לחלוניות העזרה

התפלגות סטציונרית

וקטור הסתברויות גבולי \(\pi\) הנשמר תחת פעולת מטריצת המעברים של השרשרת (\(\pi = \pi P\)). בשרשרת ארגודית התפלגות זו יחידה, ומשמעותה היא תוחלת הזמן היחסי שההילוך מבלה בכל מצב.

המשפט המרכזי של שרשראות מרקוב

משפט הקובע כי לכל שרשרת מרקוב סופית, אי־פריקה ובלתי־מחזורית, קיימת התפלגות סטציונרית יחידה \(\pi\). בנוסף, ההתפלגות הופכית לתוחלת זמן החזרה לכל מצב \(v\) (\(h_{v,v} = 1/\pi_v\)).

אי־פריקות ובלתי־מחזוריות

התנאים לקיום התפלגות סטציונרית יחידה. "אי־פריקה" (Irreducible) פירושה שקיים מסלול מכל קדקוד לכל קדקוד אחר. "בלתי־מחזורית" (Aperiodic) פירושה שהמחזור המשותף המקסימלי לכל זמני החזרה הוא 1 (מובטח, למשל, כשקיימת לולאה עצמית בגרף).

זמן חזרה / תוחלת הגעה (\(h_{u,v}\))

תוחלת מספר הצעדים המינימלי הנדרש להגיע מקדקוד התחלה \(u\) לקדקוד יעד \(v\). אם \(u=v\), זהו זמן החזרה אל הקדקוד לאחר עזיבתו.
