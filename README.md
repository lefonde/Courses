## הנתונים האישיים שלך

GitHub Pages מארח קבצים סטטיים בלבד. ההתקדמות נשמרת בדפדפן שבו עובדים, ואינה נשלחת למאגר או מסתנכרנת בין מחשבים. השמירות האחרונות נשמרות גם כגיבויים באותו דפדפן. מחיקת נתוני האתר או שימוש בפרופיל אחר עלולים לנתק אותך מהעותק הזה.

ב״הגדרות וגיבוי״ אפשר לייצא קובץ התקדמות ולייבא אותו בדפדפן אחר. לפני יבוא מוצג מסך אישור; הגיבוי מחליף את ההתקדמות באותו דפדפן. אל תצרף קובצי התקדמות למאגר הציבורי. נתוני האבחון האישיים אינם נמצאים בתוכנית הציבורית; גיבוי אישי יכול לשחזר אותם באופן מקומי.

## קישור חומרי הקורס

קובצי ה־PDF של הספר, ההרצאות, המטלות ודוגמאות הבחינה אינם נמצאים במאגר הזה. לשימוש בקישורי המקורות:

1. פתח את ״חומרי הקורס״ באתר.
2. בחר את תיקיית הקורס שלך, או את קובצי ה־PDF באמצעות הפעולה המוצגת שם.
3. האתר מתאים את שמות הקבצים לרשימת המקורות ושומר עותק בדפדפן באמצעות IndexedDB. הקבצים אינם מועלים ל־GitHub או לשרת.
4. קישור למקור פותח את העותק המקומי במציג ה־PDF, בעמוד המצוין.

יש לקשר את הקבצים מחדש בכל דפדפן חדש. גיבוי ההתקדמות אינו כולל את קובצי ה־PDF. קישור הקבצים בדפדפן אינו מעניק ל־AI גישה אליהם. הבקשות למורה AI מיועדות לשיחה עם מחברת NotebookLM שבה חומרי הקורס כבר זמינים, ומפנות למקורות המחברת לפי שמם, בלי לבקש הרשאות ל־Drive או ל־Workspace.

## התוכנית והכרטיסיות

התוכנית מיועדת לבחינה ב־23.11.2026: 28 מפגשים בשבעה שבועות ו־63 שעות הכוללות הפסקות ושש שעות עתודה. שני ורביעי מוקצים ל־90 דקות, ושישי ושבת ל־180 דקות. שעות ההתחלה לבחירתך. זמן נוסף של חצי שעה עד שעה אינו נדרש לכיסוי הליבה, כי תדירותו טרם נקבעה.

בתחילת המחזור מוצגת הפעולה ״להתחיל את תוכנית נובמבר״. היא שומרת עותק של התיעוד הקודם בהיסטוריה ומתחילה משימות, שאלות וכרטיסיות ללא סימוני למידה. היסטוריה אישית נשארת בדפדפן ובקובצי הגיבוי; היא אינה חלק מקובצי האתר הציבורי. שינוי שיבוץ מוצג כהצעה לעיון ולאישור, וניתן לבדוק ולבטל שינוי שאושר בלי למחוק התקדמות מאוחרת.

מפת השאלות כוללת את 14 שאלות החובה, שלוש דוגמאות המרצה ומשפחות הכיתה. בנק של 30 מועמדות מקושר למקורות האלה ולשמונה מבחני עבר; הוא אינו מוסיף ספירה כפולה לשאלות החובה. זהו תעדוף לימודי מתוך אוסף קטן ולא אקראי, ולא תחזית סטטיסטית להופעת שאלות. פתרון עם עזרה, פתרון עצמאי ופתרון בזמן נשמרים בנפרד.

כרטיסיות ותרגול מלא בבנק נפתחים לאחר אישור מפורש שהחומר הרלוונטי נלמד. הכרטיסיות מתאימות להגדרות, תנאים, רעיונות ושלדי הוכחה; הן אינן מחליפות פתרון של שאלות מלאות. מרווחי החזרה מותאמים לשבעת שבועות ההכנה ומסתיימים בערב הבחינה, ב־22 בנובמבר בשעה 20:00 בישראל.

## חוזרים למסלול

הפעולה ״חוזרים למסלול״ בודקת את העבודה שנותרה, את הזמינות ואת סדר הלימוד בשלושה צעדים. אפשר לעדכן התקדמות ואומדן המשך, להשתמש בעתודה במפורש, לבדוק חלונות נוספים ולנעול מועדים חשובים. סימולציות יכולות לזוז כאשר לא ננעלו. כל שינוי נשאר טיוטה עד לעיון ושמירה.

כשלא נמצא מקום לכל החומר, אפשר לשמור תוכנית חלקית רק לאחר אישור הרשימה שלא שובצה. העבודה הזאת נשארת במבט על ובלוח הזמנים, ואינה תופסת זמן בתאריכים הישנים. אין מחיקה של הערות, ניסיונות או סימוני שליטה. ב״מה השתנה בתוכנית?״ אפשר לבדוק ביטול בטוח; כשמועדים קודמים כבר חלפו, מכינים המשך מהיום.

כללי המודל, גבולות החיפוש ושערי הבדיקה מתועדים ב־[PLANNING.md](PLANNING.md). בדיקות: `npm test` עם Node 20 ומעלה, ללא התקנת חבילות. בדיקות התהליך אינן מחליפות בדיקת תצוגה במחשב ובטלפון.

## פרסום ופיתוח

קובצי האתר המוכנים נמצאים ב־`docs/`. הגדרת GitHub Pages: פרסום מהענף `main` ומהתיקייה `/docs`. אין צורך בתהליך התקנה, בבניית חבילות או בשרת Python כדי להפעיל את הגרסה הציבורית.

מציג ה־PDF משתמש ב־PDF.js 5.6.205 של Mozilla. קוד המציג, מפות התווים, הגופנים ומפענחי התמונה כלולים ב־`docs/vendor/pdfjs/` עם הודעות הרישוי המקוריות. אלה רכיבי תוכנה בלבד; קובצי הקורס עצמם נשארים בדפדפן.

לבדיקה מקומית של הגרסה הסטטית אפשר להריץ מתיקיית המאגר `python -m http.server 8080 --directory docs` ולפתוח `http://localhost:8080`. פתיחה באמצעות `file://` אינה מספקת את יכולות האחסון והטעינה הדרושות.

המאגר מכיל את קוד האתר ואת נתוני התוכנית הציבוריים בלבד. הוא אינו מכיל חומרי קורס מקוריים, יומן אישי, תוצאות אבחון או התקדמות שמורה.
